# Landing integrada ao ReportFlow

A landing enviada foi incorporada ao projeto Next.js principal.

- Página inicial: `/`
- Login existente: `/login`
- Planos/checkout existente: `/pricing`
- Dashboard e APIs existentes foram preservados.
- O design da landing foi convertido para CSS/Next.js para não exigir a troca do framework do projeto principal.

Para rodar:
1. `npm install`
2. `npm run dev`
3. Abra `http://localhost:3000`
